# 代币怎么上头像 (Logo) ？

{% hint style="success" %}
**一键发币：**[https://ciaotool.io/](https://ciaotool.io/)
{% endhint %}

### 🔍 为什么代币本身没有 Logo？ <a href="#wei-shen-me-dai-bi-ben-shen-mei-you-logo" id="wei-shen-me-dai-bi-ben-shen-mei-you-logo"></a>

* 在 **BSC、Ethereum 等链**上，代币的本质只是一个**智能合约**，链上**并不存在 Logo、简介、官网这些信息**。你在钱包、交易所、行情网站里看到的所有代币头像，其实都是：

> 由各个平台自行维护和展示的“元数据”

* 这些平台给代币加 Logo，主要是为了三件事：提升识别度、降低用户误操作风险，以及增强项目在用户心中的专业感和可信度。

**因此：想让代币显示 Logo，唯一的方法就是——去各个平台单独申请。**

### 🧩 从基础展示到平台认可 <a href="#cong-ji-chu-zhan-shi-dao-ping-tai-ren-ke" id="cong-ji-chu-zhan-shi-dao-ping-tai-ren-ke"></a>

1. 很多项目方在发币后，第一反应就是去申请 CMC、CoinGecko，或者希望 PancakeSwap、Uniswap 能立刻显示 Logo。
2. 不建议一上来就冲顶级平台，而是按**显示优先级 + 审核通过率**来推进。
3. 一个常见、合理的顺序是：**钱包 / 信息平台 → 区块浏览器 → 数据聚合平台 → 自动抓取**

### 🎯 常见的钱包与信息平台 <a href="#chang-jian-de-qian-bao-yu-xin-xi-ping-tai" id="chang-jian-de-qian-bao-yu-xin-xi-ping-tai"></a>

#### **1. Ave.ai（信息聚合平台）**

**Ave.ai 信息聚合平台:** 通常会同时展示代币 Logo、简介、官网和社交链接，流程简单、审核友好，非常适合新项目或 Meme 代币。

* **申请方式：**&#x81EA;行联系 Ave 客服
* **要求：**&#x57FA;本没要求
* **成功率：**&#x9AD8;

![](https://ciaotool.gitbook.io/ciaotool/~gitbook/image?url=https%3A%2F%2F1318999599-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FSbOZgk4BvxH3NoNkiFR8%252Fuploads%252FimYfa0eUmuWCkMCH0UCs%252Fimage.png%3Falt%3Dmedia%26token%3Dcc9754a7-97fa-4be5-86c8-f3fc85317c7a\&width=768\&dpr=4\&quality=100\&sign=2fa9efc2\&sv=2)

一旦 Ave 显示成功，**很多第三方工具和插件也会同步抓取信息**。

#### **2. TokenPocket（TP 钱包）**

**TP 钱包**的代币 Logo 是通过官方申请表提交，需要严格按文档格式提交，会检查合约是否存在黑名单、暂停交易等高风险逻辑。

* **申请方式：**&#x81EA;行提交申请表
* **要求：**&#x6B63;规的官网、代币信息，合约没有黑名单/暂停交易等功能
* **成功率：**&#x4E2D;高

👉 **官方提交文档：**[https://www.tokenpocket.pro/zh/submit/token](https://www.tokenpocket.pro/zh/submit/token)

* **要求：**&#x6B63;规的官网、代币信息，合约没有黑名单/暂停交易等功能

#### **5. imToken 钱包**

imToken 的逻辑比较特殊，只要符合 **ERC20和 EOS 代币标准，**&#x5E76;且链上存在**成功的转账记录，**&#x94B1;包就能自动识别并显示代币。

imToken 还支持项目方通过 **GitHub** 自主提交或修改 Token 信息，包括：**Token 名称、Symbol、Logo。**

* **申请方式：**&#x81EA;行提交申请表
* **要求：**&#x7B26;合 **ERC20和 EOS 代币标准，**&#x5E76;且链上存在**成功的转账记录**
* **成功率：高**

**👉 官方教程：**[https://github.com/consenlabs/token-profile/blob/master/README.zh-CN.md](https://github.com/consenlabs/token-profile/blob/master/README.zh-CN.md)

#### **6. Trust Wallet**

Trust Wallet 使用的是一个**社区维护的 Token 信息库**，需要通过 GitHub 提交审核维度非常多（官网、社交、邮箱、创建者钱包等），审核周期长，通过率相对较低。

* **申请方式：**&#x81EA;行提交
* **要求：**&#x6B63;规的官网、代币信息，社交媒体链接、官网邮箱、创建者钱包
* **成功率：低**

**👉 官网：**[https://assets.trustwallet.com/](https://assets.trustwallet.com/)

### 🔗 区块浏览器的代币 Logo 申请 <a href="#qu-kuai-liu-lan-qi-de-dai-bi-logo-shen-qing" id="qu-kuai-liu-lan-qi-de-dai-bi-logo-shen-qing"></a>

所谓“区块浏览器 Logo”，指的是在对应公链的**官方区块浏览器**中显示代币图标，例如：

* **BSC** → [BscScan](https://bscscan.com/)
* **Ethereum** → [Etherscan](https://etherscan.io/)

一旦浏览器侧成功显示：钱包、数据平台、DEX等**都有更高概率自动抓取你的代币 Logo。**&#x4F46;需要注意：审核要求通常较高、更偏向“有官网、有社交、有持续运营”的项目。

* **申请方式：**&#x81EA;行提交申请表
* **要求：**&#x6B63;规的官网、代币信息，社交媒体链接、官网邮箱、创建者钱包
* **成功率：低**

### 📊 PancakeSwap / Uniswap 的更新 <a href="#pancakeswap-uniswap-de-geng-xin" id="pancakeswap-uniswap-de-geng-xin"></a>

对于普通代币，PancakeSwap / Uniswap 本身没有一个像 Ave.ai 那样的直接付款或简单申请通道，Logo 显示取决于以下因素:

* **钱包/平台收录：** 代币需要先在 TP钱包、Bitget钱包 等钱包中显示 Logo。
* **数据聚合平台收录：** 代币被 CoinMarketCap (CMC) 或 CoinGecko (CG) 收录，有时会同步这些数据。
* **去中心化收录（DEX聚合）：** 通过 DEXTools 等工具间接或项目方自行更新资料来影响显示。

### 💡 MetaMask（小狐狸钱包）logo更新 <a href="#metamask-xiao-hu-li-qian-bao-logo-geng-xin" id="metamask-xiao-hu-li-qian-bao-logo-geng-xin"></a>

#### **⬆️ 等待官方数据检索或手动更新**

* 代币已经被收录在主流平台（如 CG、CMC、Etherscan 等），等待更新即可。
* 如果未更新，用户可通过这些平台去一键添加，将代币及其官方 Logo 自动添加进钱包，确认钱包弹窗即可。

{% hint style="warning" %}
**注意：**&#x624B;动更新的前提是已被主流平台收录。
{% endhint %}
