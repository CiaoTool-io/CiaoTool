# Solana - Tax Fee Claim Tutorial

## What is CiaoTool Solana Token Tax Fee Claim?

CiaoTool Solana Token Fee Withdrawal is an on-chain collection tool for Token-2022 fee-enabled tokens. A wallet with fee withdrawal authority can collect withheld fees accumulated across Token Accounts and withdraw them to a designated recipient account.

Token-2022 fees are not transferred to the project wallet in real time. Instead, they are temporarily withheld in recipient Token Accounts. CiaoTool uses Solana’s official fee instructions to simplify fee lookup, collection, and withdrawal for centralized fund management.
