# Solana - 靓号地址生成教程

## CiaoTool Solana 靓号地址生成是什么？ <a href="#definition" id="definition"></a>

<figure><picture><source srcset="../../../.gitbook/assets/屏幕截图 2026-09-07 151857.png" media="(prefers-color-scheme: dark)"><img src="../../../.gitbook/assets/image (796).png" alt="CiaoTool Solana网络 靓号地址生成 功能页面"></picture><figcaption></figcaption></figure>

**Solana 靓号地址**生成是 CiaoTool 提供的免费钱包工具。您可以设置希望出现在钱包地址开头或结尾的字符，例如以 `soL` 开头、以 `pump` 结尾，工具会持续生成随机密钥对，直到找到符合条件的地址。

生成结果包含钱包地址及其对应私钥。靓号地址具有与普通 Solana 钱包地址相同的用途，区别在于部分字符符合您设定的规则。它会生成一个新钱包，不会修改已有钱包的地址。

**适用场景：**

* 专属代币地址：\
  使用指定字符作为地址前缀或后缀，让钱包更容易辨认。
* 官网运营钱包：\
  为项目或社区生成具有辨识度的钱包地址，用于公开展示。

### 设置地址前缀或后缀

在「靓号前缀」和「靓号后缀」中填写希望匹配的字符。您可以只填写其中一项，也可以同时填写两项。

<figure><img src="../../../.gitbook/assets/image (797).png" alt=""><figcaption></figcaption></figure>

| 生成目标          | 靓号前缀  | 靓号后缀   |
| ------------- | ----- | ------ |
| 地址以 `soL` 开头  | `soL` | 留空     |
| 地址以 `pump` 结尾 | 留空    | `pump` |
| 同时匹配开头和结尾     | `soL` | `pump` |

匹配字符越长、条件越多，通常需要尝试的地址数量也越多。首次使用建议先设置较短的前缀或后缀。
