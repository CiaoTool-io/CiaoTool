## Uniswap 创建 V3 流动性池是什么？

<figure><img src="../../../../.gitbook/assets/image (706).png" alt="CiaoTool Robinhood链 创建 V3 流动性资金池页面"><figcaption></figcaption></figure>

CiaoTool Create V3 Liquidity Pool 是一款用于在 Robinhood Chain 上创建和初始化 Uniswap V3 集中流动性池的无代码工具。

Uniswap V3 Pool 是一个支持交易者在两种资产之间进行兑换的智能合约。与将流动性分布在完整价格曲线上的 V2 不同，V3 允许流动性提供者将资产部署在指定价格范围内。

将流动性集中在选定范围内，可以提高资金利用率，并在目标价格附近提供更深的有效流动性。但 V3 需要更加精确的参数设置，包括代币交易对、手续费等级、初始价格、最低价格、最高价格和流动性数量。

CiaoTool 将这些智能合约交互简化到一个操作页面中。用户只需输入代币地址、选择手续费等级、设置初始价格和流动性范围、检查所需资产数量并完成必要授权，即可提交建池交易，无需编写代码。

## 如何选择 V2 / V3 流动性池？

<table data-search="false"><thead><tr><th>对比维度</th><th>V3 流动性池</th><th>V2 流动性池</th></tr></thead><tbody><tr><td>流动性分布</td><td>集中流动性 (自定义价格区间)</td><td>全区间覆盖</td></tr><tr><td>资金利用率</td><td>极高。相比 V2，资金效率最高可提升 4000 倍。</td><td>较低。大量资金闲置在极端价格，未被有效利用。</td></tr><tr><td>操作门槛</td><td>较高。需自行设定和调整流动性的价格上限和下限。</td><td>极低。只需输入代币数量和 BNB 比例即可一键建池。</td></tr><tr><td>手续费机制</td><td>提供多个费率级别（如 0.01%, 0.05%, 0.25%, 1%），可根据资产波动性自定义。</td><td>固定收取 0.25% 交易手续费。</td></tr><tr><td>无常损失风险</td><td>较高风险。由于资金集中，若价格跌出你设定的区间，价格将瞬间击穿。</td><td>标准风险。资产价格变动带来的损失相对可预测。</td></tr><tr><td>滑点表现</td><td>在设定的流动性区间内，滑点极低，交易体验极佳。</td><td>在大额交易时，容易产生较大滑点。</td></tr><tr><td>代币经济学兼容</td><td>部分具有复杂机制的代币在 V3 部署时可能出现兼容性问题。</td><td>完美兼容所有类型的代币。</td></tr></tbody></table>

<figure><img src="../../../../.gitbook/assets/image (681).png" alt=""><figcaption></figcaption></figure>

### 设置手续费级别

<figure><img src="../../../../.gitbook/assets/image (682).png" alt=""><figcaption></figcaption></figure>

交易费用不同：V3 有四种不同的交易费等级，最多可比 V2 降低 25 倍交易费用；V2 每一笔交易将支付 0.25% 手续费。您也可以选择 1% 以获得更高的 LP 收益。
{% endstep %}

{% step %}
### 设置初始价格与价格区间

<figure><img src="../../../../.gitbook/assets/image (683).png" alt=""><figcaption></figcaption></figure>

1. 区间大小決定收益高低 (LP 手续费收益适用)

* 越窄收益越高，无常损失越大；
* 越宽收益越低，无常损失越小；
* 全区间设置则类似于 V2 运作，收益将非常少。

2. 超出区间时

* V3 池无收益；
* 流动性仓位将变为单币；
* 可以移除流动性并重新添加，或是等待价格重新回到区间内。
* 可以添加 V2 流动性池，确保 V3 区间外基础流动性。
{% endstep %}

{% step %}
### 输入加池代币数量

分别输入两个加池代币放入流动性资金池的代币数量，请自行计算合适的比例后并确定初始币对价格后再创建流动性。

初始币对价格：`项目代币 / 计价代币 = 初始价格`

<figure><img src="../../../../.gitbook/assets/image (676).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### 确认交易

{% hint style="danger" %}
每个不同币对 / 不同税率的 V3 流动性池，有不同的币对地址，请务必保存币对合约地址信息，并将 LP 凭证保存至您的 Web3 钱包中。
{% endhint %}

确认信息无误后，点击下&#x65B9;**「开始交易」**&#x6309;钮，并等待创建流动性池完成。
{% endstep %}
{% endstepper %}

## 常见问题

<details>

<summary><strong>什么是 Uniswap V3 流动性池？</strong></summary>

Uniswap V3 Pool 允许流动性提供者将资产部署在指定价格范围内。每个仓位由 NFT 表示，并且只有在池子价格位于设置范围内时才处于有效状态。

</details>

<details>

<summary><strong>V2 和 V3 流动性有什么区别？</strong></summary>

V2 将流动性分布在完整价格曲线上；V3 允许将流动性集中在指定价格范围内，可以提高资金利用率，但需要更精确的参数设置和主动仓位管理。

</details>

<details>

<summary><strong>是否需要编程经验？</strong></summary>

不需要。CiaoTool 提供可视化页面，用于设置和提交所需的 V3 智能合约交互。

</details>

<details>

<summary><strong>什么决定初始价格？</strong></summary>

新 V3 Pool 初始化时需要设置初始价格。请仔细核对代币顺序、Decimals 和页面显示价格。

</details>

<details>

<summary><strong>如果价格超出流动性范围会怎样？</strong></summary>

流动性仓位会变为非活跃状态，并停止赚取 Swap 手续费，直到价格重新回到设定范围。根据价格变化方向，仓位可能主要或完全由其中一种代币组成。

</details>

<details>

<summary><strong>所有代币都可以使用 V3 流动性吗？</strong></summary>

不一定。带有转账税、Rebase、持币分红、黑名单、交易限制或其他自定义转账逻辑的代币，可能无法与 Uniswap V3 正常配合。

</details>

<details>

<summary><strong>之后可以修改价格范围吗？</strong></summary>

现有 V3 仓位的价格范围通常不能直接修改。如果需要使用新的范围，一般需要先移除流动性，再创建新的仓位。

</details>

<details>

<summary><strong>什么决定 V3 流动性所需的代币数量？</strong></summary>

所需资产比例取决于初始价格、选定价格范围、代币 Decimals 和当前池子价格。

</details>

<details>

<summary><strong>为什么不同钱包的成交价格可能不同？</strong></summary>

每个钱包都会提交一笔独立交易。每次买入成功后，池子状态都会发生变化，网络延迟、RPC 响应时间、Sequencer 到达顺序、滑点和第三方交易也可能影响成交结果。

</details>

<details>

<summary><strong>所有代币都可以使用 V3 吗？</strong></summary>

不一定。带有转账税、持币分红、Rebase、黑名单、交易限制或其他自定义转账逻辑的代币，可能无法与 Uniswap V3 正常配合。

</details>

<details>

<summary><strong>创建池子后，代币会自动显示在所有平台吗？</strong></summary>

不会。创建池子可以开启对应交易对的链上交易，但外部页面、Token List、数据分析平台和索引器可能需要额外审核或索引时间。

</details>
