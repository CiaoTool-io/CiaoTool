## 常规合约代币 <a href="#contract-token-creator" id="contract-token-creator"></a>

常规合约代币是基于链上智能合约独立创建的标准化代币类型，拥有更高的自由度、可扩展性与自主运营能力。项目方可根据自身需求自由构建代币经济学、交易机制与社区玩法，更适合长期运营、品牌建设与生态发展。

该模式支持完整的合约控制与功能扩展，可灵活实现税费、分红、燃烧、回流、黑洞、持币奖励等多种机制，同时具备更强的可持续运营能力与生态成长空间。无论是社区 Meme、品牌项目、DAO 生态，还是长期运营型代币，都能够通过常规合约模式实现更完整的项目规划。

相比快速发射型玩法，常规合约代币更强调项目独立性、长期价值与生态沉淀，适合希望持续运营社区、打造项目品牌并建立长期市场影响力的团队与开发者。

## 内盘发射代币 <a href="#meme-launch" id="meme-launch"></a>

内盘发射代币是依托 Launchpad 平台进行创建与启动的轻量化发币模式，平台会自动完成创建、发射、定价、交易与流动性等流程，大幅降低发币门槛与启动成本，更适合热点玩法与 Meme 市场快速启动。

该模式拥有更快的创建速度与更低的操作复杂度，用户无需进行繁琐配置即可快速完成代币发射，并借助平台自身的交易环境与流量机制获得初始曝光，更容易形成早期热度与市场传播。

相比传统合约模式，内盘发射代币更加偏向流量驱动与市场节奏，适合短周期运营、热点追踪、社区测试与 Meme 冷启动等场景，能够帮助项目以更轻量、更直接的方式快速进入市场。
