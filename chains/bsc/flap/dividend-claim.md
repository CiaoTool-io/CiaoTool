# Flap - 分红提取指南

## 功能介绍

**CiaoTool Flap 分红提取**是一款面向 BNB Chain 的批量持币分红领取工具，支持 Flap.sh 的税费代币。

用户可批量导入代币与持币地址，系统自动查询待领取分红、核验领取状态并分组提交交易。付款钱包统一支付 BNB Gas 和平台服务费，分红则直接发送至对应的权益地址，不会改变原有分红归属。

**适用场景：**

* 多钱包持币分红批量领取
* 项目方及运营钱包收益归集
* 为其他持币地址代付领取费用
* 多代币、多地址分红统一管理
* 批量查询待领取金额与执行状态

## 核心优势

* **批量领取：** 支持一次导入多条代币与接收地址记录
* **灵活配置：** 支持统一或逐条设置代币地址与接收地址
* **自动核验：** 自动查询税收信息、待领取金额及领取状态
* **本地安全：** 私钥仅在本地用于交易签名，不会上传或保存至服务器

## 图文指南

{% stepper %}
{% step %}
### 输入付款钱包

在「付款钱包私钥」中输入用于执行领取任务的钱包私钥。

付款钱包负责：

* [x] 调用 Flap 分红合约
* [x] 支付 BNB Gas
* [x] 支付平台服务费
{% endstep %}

{% step %}
### 设置代币地址

选择代币地址的配置方式：

* **统一代币地址：** 所有记录使用同一个代币合约地址
* **每条不同代币地址：** 为每条领取记录分别设置代币地址

选择统一代币后，在下方输入需要领取分红的代币合约地址。
{% endstep %}

{% step %}
### 设置接收地址

选择分红接收方式：

* **统一接收地址：** 所有分红发送至同一个权益地址
* **地址本身：** 每条记录的持币地址作为对应接收地址

接收地址必须拥有该代币的 Flap 分红权益。付款钱包只能代付领取费用，无法改变分红归属。
{% endstep %}

{% step %}
### 导入分红列表

点击「导入分红列表」，粘贴 Excel 数据或上传地址文件。

不同模式对应的导入格式如下：

* **统一代币＋地址本身：** 每行输入一个接收地址
* **每条不同代币＋统一接收地址：** 每行输入一个代币地址
* **每条不同代币＋地址本身：** 每行输入“代币地址＋接收地址”
* **统一代币＋统一接收地址：** 系统自动生成一条领取记录

系统会自动过滤无效记录，并对重复的“代币地址＋接收地址”组合进行去重。
{% endstep %}

{% step %}
### 检查列表

导入完成后，点击「刷新检查」。

系统将优先检查前 10 条记录，并展示：

* 代币及税收信息
* 分红接收地址
* 待领取金额
* 当前领取状态
* 异常或跳过原因

其余记录将在任务开始后继续分组检查。
{% endstep %}

{% step %}
### 开始提取分红

确认信息无误后，点击「开始提取分红」。

系统将自动：

1. 每组检查 10 条领取记录
2. 再次核验待领取分红
3. 检查 Gas、服务费及付款钱包余额
4. 每批最多捆绑提交 20 笔领取交易
5. 上一批确认后继续处理下一批记录
{% endstep %}
{% endstepper %}
